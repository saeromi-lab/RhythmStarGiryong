# 프로젝트 개요

## 목적

**RhythmStarGiryong**은 경기대학교 **실용음악학과** 재학생이 리듬·박자 감각을 꾸준히 훈련하도록 돕는 **아케이드형 웹 앱**입니다.

- 운동부·체육 스포츠와 **무관**
- 음악 전공 실기(보컬, 작곡, 연주, 프로듀싱 등)에 필요한 **리듬 감각** 향상
- **매일 접속** 동기 부여: 출석 보상, 랭킹 경쟁, 기룡이 캐릭터

## 캐릭터: 기룡이

경기대학교 공식 마스코트 **기룡이**가 앱의 중심 캐릭터입니다.

- 출석·플레이 결과에 따라 반응·응원 멘트
- 학생들이 친숙하게 느끼는 브랜드 아이덴티티 활용

## 게이미피케이션 요소

| 요소 | 설명 |
|------|------|
| 출석 체크 | 매일 코인·XP 보상, 연속 출석 보너스 |
| 레벨·XP | 플레이를 통해 성장, Lv. 표시 |
| 아케이드 모드 | TAP! 타이밍 게임, COMBO·판정 |
| 주간 랭킹 | 학과 동기들과 점수 경쟁 |
| 일일 미션 | 출석, 플레이, COMBO 목표 |

## Change the world through rhythm

리듬 감각은 연주·작곡·보컬·프로듀싱 모든 분야의 기초입니다.  
재미있게, 매일, 함께 연습하는 것이 이 프로젝트의 핵심입니다.
