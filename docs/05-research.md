# 연구 자료

## 주요 학술 논문

### 1. 여중생 대상 12주 프로그램 연구

**논문**: 스포츠리듬트레이닝이 여중생의 학생건강체력과 인지기능에 미치는 영향  
**저자**: 김서인, 박순희, 변재경  
**학술지**: 한국여성체육학회지, 2020, 34(4), 141-153  
**DOI**: https://doi.org/10.16915/jkapesgw.2020.12.34.4.141

**연구 설계**

- 대상: 여중생 46명 (운동집단 23명, 통제집단 23명)
- 기간: 12주, 주 2회, 회당 45분
- 프로그램: 리듬점프 10스텝 + STAR MOVE 1,2,3

**주요 결과**

| 변인 | 운동집단 | 통계적 유의성 |
|------|----------|---------------|
| 유연성 | 향상 | p < .001 |
| 순발력 | 향상 | p = .05 |
| 심폐지구력 | 향상 | p < .001 |
| 근력·근지구력 | 향상 | p < .001 |
| 체지방률(BMI) | 변화 없음 | p = .940 |
| 스트룹 색상 검사 | 향상 | p = .021 |
| 스트룹 단어 검사 | 향상 | p = .019 |
| 스트룹 색상-단어 검사 | 향상 | p = .001 |

**결론**: 12주 스포츠리듬트레이닝은 여중생의 건강체력과 인지기능 향상에 유용한 프로그램
