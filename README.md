# RhythmStarGiryong

경기대학교 **실용음악학과** 학생을 위한 리듬 트레이닝 웹앱입니다.

**기룡이**(경기대 마스코트)와 함께 **매일 강의로 개념을 익히고**, 메트로놈으로 손을 맞춘 뒤, 게임으로 복습합니다.

> 운동부·체육 스포츠와는 무관하며, 실용음악 전공생의 리듬 감각 향상이 목적입니다.

## 실행 방법

```bash
chmod +x setup.sh
./setup.sh
npm run dev    # http://localhost:3000
```

## 오늘의 훈련 순서

1. **강의** — 오늘 단원의 개념을 읽고 예제 악보를 확인
2. **연습** — 메트로놈을 켜 두고 같이 친 다음, 같은 리듬을 따라 치기
3. **확인** — 배운 내용을 퀴즈로 점검
4. **게임 (선택)** — 비트 서핑으로 같은 TAP을 복습

## 주요 기능

| 기능 | 설명 |
|------|------|
| **기룡이 캐릭터** | 마스코트가 응원·피드백 제공 |
| **출석 체크** | 매일 출석, 연속 출석 보상 (코인·XP) |
| **단원 강의** | 2연음부터 16분까지 8과 개념 학습 |
| **메트로놈 연습** | 같이 치기 → 따라 치기 |
| **확인 퀴즈** | 단원별 이해 점검 |
| **비트 서핑** | 선택 복습 게임 |
| **랭킹** | 주간 학과 연습 점수 |
| **커리큘럼** | 12주 단계별 리듬 트레이닝 과정 |
