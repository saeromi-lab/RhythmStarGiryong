# 경기대학교 스포츠리듬트레이닝 적용

## 경기대학교와 STAR

경기대학교는 스포츠리듬트레이닝협회(STAR)와 협력하여 운동부 선수들의 **퍼포먼스 향상**과 **부상 예방**을 위한 리듬 트레이닝을 도입·활용하고 있습니다.

## 주요 적용 대상 운동부

### 조정부

- **창단**: 1973년
- **슬로건**: "One Boat, One Mind"
- **특징**: 대한민국 조정 역사를 대학부 최초로 써 내려가는 엘리트 팀

**STAR 리듬훈련 적용 목적**

- 노 젓기 동작의 **타이밍·호흡 조화** 향상
- 팀 내 **동기화(싱크)** 강화
- 부상 없이 **운동 성능** 극대화

**주요 성과 (선수)**

| 선수 | 주요 성과 |
|------|-----------|
| 김슬기 (07학번) | 2014 인천 AG 쿼드러플스컬 은메달, 2018 자카르타 AG 더블스컬 은메달 |
| 지유진 (07학번) | 2014 인천 AG 경량급 싱글스컬 금메달 |
| 김수현 (20학번) | 2022 항저우 장애인 AG 유타포어 은메달 |
| 서하경 (21학번) | 2024 파리 패럴림픽 유타포어 출전 |

**지역 연계**: 2023년 수원조정클럽과 발전기금 협약, 지역사회와 상생

- 운동부 소개: https://www.kyonggi.ac.kr/www/contents.do?key=5124

### 배구부

- **창단**: 1950년 (1972년 재창단)
- **별칭**: "배구하면 경기대학교"
- **최근 성과**: 2023년 KUSF U-리그 대학배구 10년 만에 우승

**STAR 리듬훈련 적용 목적**

- 스파이크·블로킹 등 **타이밍 동작** 개선
- **점프·착지** 시 부상 예방
- 팀 전술 실행 시 **리듬감** 향상
